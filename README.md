# Tasty Trails 🍽️

> *"Every Bite Begins a Beautiful Journey."*

Tasty Trails is a modern, responsive, and elegant restaurant website built strictly with **pure HTML5 and CSS3** (no JavaScript, no CSS frameworks). It features fine-dining aesthetics, fluid typography, rich food photography, an interactive menu grid, an artisanal story section, and an accessible contact form.

---

## ✨ Features

- **Semantic HTML5 & Pure CSS3**: Clean, standards-compliant, lightweight, and zero external JS/framework dependencies.
- **Brand Palette**:
  - Primary: Deep Burgundy (`#651B2A`)
  - Secondary: Warm Cream (`#FFF8EF`)
  - Accent: Golden Yellow (`#D9A441`)
  - Text: Dark Charcoal (`#292525`)
  - Background: Crisp White (`#FFFFFF`)
- **Typography**:
  - Headings: *Playfair Display* (Google Fonts)
  - Body: *Poppins* (Google Fonts)
- **Responsive Layout**:
  - Desktop: 3 menu cards per row
  - Tablet: 2 menu cards per row
  - Mobile: 1 menu card per row with a pure CSS hamburger menu
- **Interactive Micro-Interactions**:
  - Smooth card elevation and image zoom on hover
  - Animated golden underline navigation hover effect
  - Smooth scrolling navigation (`scroll-behavior: smooth`)
- **Full Favicon Suite**:
  - SVG vector favicon, multi-resolution `favicon.ico`, and high-density PNG icons for iOS and Android.

## 🚀 Getting Started

No build tools, package managers, or server installations required.

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Dhuvaragish/tasty-trails.git
   ```
2. Open `index.html` directly in any modern web browser.

---

## 🌐 Deploy to GitHub Pages

To host this website live for free on GitHub Pages:
1. Push this repository to your GitHub account.
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Branch**, select `main` (root) and click **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`!
